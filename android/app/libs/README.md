Place the **Samsung Health Data SDK v1.1.0** library here as
`samsung-health-data-api-1.1.0.aar` after downloading it from
https://developer.samsung.com/health/data/overview.html and reviewing Samsung's
license. Use the library from the SDK archive's `libs/` directory, not the legacy
Samsung Health SDK for Android. The binary is deliberately ignored by Git.
See [the validation guide](../../../docs/ANDROID_HEALTH_VALIDATION.md).
